# Aura - Modern Flutter App

A beautiful, modern Flutter application with a clean navigation bar design that works seamlessly on both iOS and Android.

## Features

- Modern Material Design 3 UI
- Adaptive dark/light theme support
- Beautiful gradient cards and smooth animations
- Clean bottom navigation bar
- Three main sections: Home, Explore, and Profile
- Responsive design that works on both mobile platforms

## Screens

### Home Screen
- Welcome banner with gradient design
- Quick action cards for common tasks
- Modern card layouts with icons

### Explore Screen
- Search functionality
- Category filters
- Grid layout for content browsing
- Trending items section

### Profile Screen
- User profile with avatar
- Statistics display (posts, followers, following)
- Settings and preferences
- Account management options

## Getting Started

### Prerequisites
- Flutter SDK (3.0.0 or higher)
- Dart SDK (3.0.0 or higher)

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Run the app:
   ```bash
   flutter run
   ```

## Platform Support

- iOS
- Android
